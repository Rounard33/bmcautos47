ÉTAPE 1 : Configurer Vercel (5 minutes)
─────────────────────────────────────────
1. Allez sur https://vercel.com/dashboard
2. Sélectionnez votre projet
3. Settings → Environment Variables
4. Ajoutez ces 3 variables :

   KEPLER_API_KEY=votre_vraie_cle_api
   KEPLER_DEALER_ID=votre_id_concessionnaire
   KEPLER_API_URL=https://api.kepler-soft.net/v3.60

5. Cochez : ✅ Production ✅ Preview ✅ Development

ÉTAPE 2 : Déployer (1 minute)
──────────────────────────────
git add .
git commit -m "Add Vercel proxy for KeplerVO API"
git push

→ Vercel déploiera automatiquement

ÉTAPE 3 : Tester le proxy (2 minutes)
──────────────────────────────────────
# Remplacez par votre URL Vercel
curl https://votre-site.vercel.app/api/vehicles

Réponse attendue :
{
  "success": true,
  "data": [...]
}

ÉTAPE 4 : Vérifier la sécurité (1 minute)
──────────────────────────────────────────
1. Ouvrez votre site
2. F12 → Network → Rafraîchir
3. Cliquez sur un fichier .js
4. Cherchez "apiKey"

✅ Vous devriez voir : apiKey: ""
❌ Vous ne devriez PAS voir : apiKey: "votre_vraie_cle"

ÉTAPE 5 : Activer l'API (optionnel)
────────────────────────────────────
Quand vous êtes prêt à utiliser l'API réelle :

1. Modifiez src/environments/environment.prod.ts :
   useMockData: false  // ← Changez true en false

2. Déployez :
   git add src/environments/environment.prod.ts
   git commit -m "Activate KeplerVO API"
   git push

╚══════════════════════════════════════════════════════════════════════════════╝

Erreur : "API configuration error"
───────────────────────────────────
→ Vérifiez que KEPLER_API_KEY est bien dans Vercel
→ Redéployez après avoir ajouté la variable

Erreur : "Authentication failed"
─────────────────────────────────
→ Vérifiez votre clé API KeplerVO
→ Vérifiez la méthode d'auth dans /api/vehicles.ts
   (Bearer vs X-API-Key)

Erreur : "Resource not found"
──────────────────────────────
→ Vérifiez l'URL de l'API (KEPLER_API_URL)
→ Consultez la doc KeplerVO

Le site charge les véhicules de démo
─────────────────────────────────────
→ Changez useMockData: false dans environment.prod.ts
→ Redéployez
→ Videz le cache navigateur (Ctrl+Shift+R)
